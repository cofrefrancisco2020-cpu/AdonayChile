# Tapicería Adonay — versión 1

Sitio web profesional para Fábrica y Tapicería Adonay, preparado como proyecto React/Vinext para repositorio GitHub y despliegue posterior.

## Abrir el proyecto

1. Instala Node.js 22 o superior y pnpm.
2. En esta carpeta ejecuta `pnpm install`.
3. Ejecuta `pnpm dev` para desarrollo o `pnpm build` para crear la versión de producción.

## Archivos principales

- `app/page.tsx`: contenido y estructura de la página.
- `app/globals.css`: identidad visual y estilos responsive.
- `app/layout.tsx`: metadatos, idioma y tipografías.
- `public/assets/`: todos los recursos visuales finales usados por la web.
- `brief-marca.md`: investigación, decisiones de contenido y procedencia de imágenes.

## Recursos visuales

La página combina el logotipo y cuatro publicaciones reales del perfil público de Instagram con tres imágenes nuevas generadas mediante IA a partir del lenguaje visual de esos productos. Las imágenes generadas son ambientaciones conceptuales y no deben presentarse como fotografías de obras ya entregadas.

## Limitaciones de investigación

El perfil público consultado no expone teléfono, correo, horarios ni precios. Por eso la llamada a la acción dirige a Instagram y no se inventaron datos comerciales. Antes de publicar con dominio definitivo conviene añadir teléfono/WhatsApp, horarios, condiciones de despacho y URL canónica.
